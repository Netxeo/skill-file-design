# Plan de Mise à Jour : Skill Design (L'Art Director Ultime)

## 1. Philosophie & Branding 
- [x] Le branding n'est pas juste une option, c'est l'âme du projet (cohérence emails, réseaux, site).
- [x] Création systématique d'un **Style Guide / Design System** (couleurs, typos, composants).
- [x] Expliquer les choix créatifs : *Pourquoi cette couleur ? Pourquoi cette typo ?*

## 2. Interaction & Onboarding Utilisateur
- [x] Ajouter une étape interactive au début du prompt : **"Avez-vous déjà un Style Guide / Branding ?"**
    - **Si Oui :** L'IA se base dessus pour garantir une cohérence parfaite.
    - **Si Non :** L'IA explique pourquoi c'est crucial, puis le crée de toutes pièces avec l'utilisateur (moodboard, charte, etc.).

## 3. Le Workflow Professionnel Stricte
L'IA doit agir comme un professionnel et suivre cet ordre précis :
- [x] **Étape 1 : Recherche & Analyse** (Compréhension de l'industrie, cible, besoins).
- [x] **Étape 2 : Architecture (UX)** (Sitemap, agencement des pages, flow utilisateur).
- [x] **Étape 3 : Style Guide / Design System (DA)** (Choix des couleurs, typos, composants visuels justifiés).
- [x] **Étape 4 : Copywriting & Contenu** (Rédaction exacte mot pour mot).
- [x] **Étape 5 : Design & Implémentation UI** (À réaliser *uniquement* quand tout ce qui précède est validé).
- [x] **Étape 6 : Responsive & Polish** (Gestion des breakpoints mobile/tablette, aucun débordement de texte, UX parfaite).
